## 📑 PhD Internship Proposal (Executive Summary)

### 1. Research Framework
* **Study 1 (Systematic Literature Review):** Mapping institutional and technical market-entry barriers for independent aggregators in European FaaS markets.
* **Study 2 (DEA System Efficiency):** Benchmarking cross-border electricity system efficiency using **SBM-DEA**, endogenizing network losses, carbon intensity, and battery degradation dynamics.
* **Study 3 (Predictive AI Pipeline):** Building an explainable ML framework (**Random Forest + GPR + SHAP**) to forecast grid congestion, negative price events, and BESS dispatch opportunities.

### 2. Technical & Methodological Toolkit
* **Quantitative & Efficiency Analytics:** SBM-DEA, Dynamic DEA, Panel Econometrics, Time-Series Analysis.
* **Grid AI & Explainability (XAI):** Python (`Scikit-learn`, `TensorFlow`, `SHAP`), Random Forest, LSTM/TCN architectures.
* **Domain Tools & Simulation:** `Pandapower`, `OpenSTEF`, ENTSO-E API pipelines.

### 3. Value Proposition for Host Institutions
* 📈 **Congestion Forecasting:** Adapting validated price/volatility predictive models to local transmission constraints.
* ⚡ **Asset Efficiency Benchmarking:** Applying DEA models to evaluate grid-scale storage portfolios or local flexibility assets.
* 📜 **Policy & Market Intelligence:** Delivering comparative insights on European Electricity Market Design (EMD) reforms.
