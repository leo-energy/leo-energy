## 📖 Research Abstract

My doctoral research develops a tripartite cumulative framework bridging strategic management, non-parametric efficiency benchmarking (SBM-DEA), and explainable machine learning (Random Forest + SHAP) to optimize Battery Energy Storage System (BESS) flexibility arbitrage under volatile European electricity markets. Key contributions include:

- **R² = 0.9655** day-ahead price forecasting in TenneT (Netherlands)
- **‑500 EUR/MWh** negative price floor capture
- **Cross-market arbitrage** using NL‑ES decoupling (r = 0.702)
